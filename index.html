About Me

I'm a Computer Engineering student at De La Salle University who loves understanding how computers actually work, all the way down to registers, buses, and clock cycles. What started as curiosity about digital logic has grown into hands-on experience designing an 8-bit CPU in Verilog, building arithmetic circuits from discrete ICs, and programming PIC and Arduino microcontrollers in Assembly and C.

I learn best by building. Every project here began as a problem I didn't yet know how to solve, and each one taught me to plan carefully, debug patiently, and document my work so that others can follow it.

Computer Architecture · Verilog

Accumulator-Based 8-bit CPU

Designed an 8-bit accumulator-based CPU with a custom 16-instruction set, written at the register-transfer level in Verilog. The datapath includes an instruction register and decoder, program counter, ALU, accumulator, flag register, and separate instruction and data memories, all driven by a finite-state-machine timing and control unit that runs the full fetch → decode → execute → write-back cycle.

  • Planned the full datapath and control signals as a block diagram before writing any code
  • Implemented arithmetic/logic operations, immediate and memory addressing
  • Verified the design through simulation and synthesized RTL
VerilogRTLFSM ControlISA Design
Digital Logic · Discrete ICs

IC-Based 4-Bit Arithmetic Calculator

Built a 4-bit calculator that adds and subtracts using only discrete logic ICs: full adders, multiplexers, and supporting gates, wired and debugged by hand on hardware.

Dual-MCU Line-Following Robot

Robot controlled by two microcontrollers communicating over USART: a PIC programmed in Assembly reads the line sensors, while an Arduino drives the motors, keeping the two processors smoothly coordinated in real time.
